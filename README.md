# 🚀 FlowPilot AI – B2B SaaS Marketing Website

A modern, responsive, and SEO-optimized multi-page marketing website built for **FlowPilot AI**, a fictional AI-powered workflow automation platform. This project demonstrates production-ready frontend development using React, focusing on accessibility, performance, reusable components, and modern UI/UX.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/imtushrpwar/FlowPilot-AI-marketing-site.git
```

Move into the project directory

```bash
cd YOUR_REPOSITORY
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Visit

```text
http://localhost:5173
```

---

# 📦 Build

Create a production build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
